# Omi App 一頁摘要

> 2026-10-09 更新：擁有者的決定都已收進來。細節在 [PRD.md](PRD.md)。

## 挑戰是什麼（5 句話）

1. **The Omi Challenge**：主辦 10/9 開跑、12/31 結束（剛好 84 天）；App 裡每個人從開始用的那天算 Day 1，結束固定 12/31。
2. 五個 Pillar：**Move 動身、Nourish 滋養、Learn 求知、Recover 恢復、Reflect 反思**。
3. **完成 = 走到最後一天沒退出**，不是每天完美。
4. 沒做到就寫在當天的心得裡，不補做、不重來。
5. **開始前先決定、之後鎖定**：三選至少二、就寢起床時間（體重不鎖）。

## 每天、每週要做什麼（Jimmy 的定義）

| 每天 | 每週（週日前） |
| --- | --- |
| 把每一個挑戰的鍵帽按一遍（含 0 酒精） | 有氧 150 分鐘、肌力 2 次 |
| 寫一句今天注意到的事／心得（例：今天忘記閱讀、感冒所以喝很多水） | 回答三題：哪裡做好／遇到什麼阻礙／下週保留或改變什麼 |
| | 1 張照片 → 照片牆 |

## 擁有者已決定

| 事項 | 決定 |
| --- | --- |
| 開跑日 | 開始用 App 那天；教學可選「從今天」或「從下週一」。結束固定 12/31 |
| 體重 | 保留、隨時可改、不鎖定；填了之後蛋白質和飲水目標都顯示 |
| 「沒做到」狀態 | 先不做，寫在心得裡 |
| 🔥 連續 N 天 | 保留；主位改「達成 N 天」，連續放不顯眼處或結束慶祝牆 |
| 0 酒精 | 每天一顆鍵帽、每天按 |
| 分享 | 只看得到打卡；心得與回顧不給人看 |
| 照片 | 先做本機照片牆；後端之後變成大家的照片牆 |
| 文案 | 語氣風格不動，只改數字和定義 |

## 這一批要改的（正在做）

1. 結束固定 12/31、開跑日可選；「100 天」改成實際天數
2. Nourish 至少選 2
3. 體重不鎖定，輸入後兩個目標都顯示
4. 首頁「達成 N 天」為主，連續 N 天縮小
5. 每週只留回顧三題；下週計畫併入第 3 題；Week 1 計畫放教學
6. 每週照片真的能選／拍，排成照片牆
7. 教學照 Mindy 的 Setup 表：決定加入與開跑日、Nourish 勾選、要讀什麼書、作息、Week 1 計畫（Move 項目＋最可能的阻礙）
8. Reflect 教學改成引導寫心得（給例子）與預覽每週三題
9. 示範鍵帽可以按；時間選擇器改像素風
10. 首頁加「本週任務」卡，回顧和照片不用再翻到每日打卡最底下

還沒決定：要不要做提醒通知；iOS 小工具的樣子是否 OK。
